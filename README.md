# ❤️ Crowdfunding Platform for Social Causes

A web-based crowdfunding platform designed to connect individuals and organizations with people willing to support meaningful social causes through online fundraising and donations.

The platform aims to simplify fundraising activities by providing an accessible and user-friendly environment where campaign creators can present their causes, reach potential donors, and receive financial support.

## 🚀 Key Features

* ❤️ **Fundraising Campaigns:** Enables individuals and organizations to create fundraising campaigns for various social causes.
* 💰 **Online Donations:** Provides a platform for supporters to contribute financially to campaigns.
* 📋 **Campaign Management:** Allows campaign creators to manage and track their fundraising activities.
* 👥 **User Management:** Supports user interactions and account management.
* 📊 **Fundraising Overview:** Helps users monitor campaign progress and donation activities.
* 🎨 **User-Friendly Interface:** Designed with a focus on accessibility, usability, and seamless user experience.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/sahatish/CrowdFunding-Platform-For-Social-Causes.git
```

### 2. Navigate to the Project Directory

```bash
cd CrowdFunding-Platform-For-Social-Causes
```

### 3. Navigate to the Frontend

```bash
cd client
```

### 4. Install Dependencies

```bash
npm install
```

### 5. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to access the application.
